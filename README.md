# prepMaxAIClient

React Native (Expo) client for PrepMax AI — a 16-week classic-physique prep coach.

## Stack

Expo SDK 52 · Expo Router · TypeScript strict · NativeWind · Reanimated 3 · PowerSync · TanStack Query · Zustand

## Getting started

```sh
npm install
npx expo start
```
